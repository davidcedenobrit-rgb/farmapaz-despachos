Features entregadas
Todo lo que Navi Dev construyó
🖥️ Módulo Monitor
✓
Panel de despachos en tiempo real CORE
Tabla con todos los pedidos del día, estados con colores, contador de tiempo activo, GPS del piloto y botones de acción por pedido.
✓
Creación y edición de pedidos CORE
Formulario modal con campos: número de factura, cliente, teléfono, dirección, descripción de productos y asignación directa de piloto.
✓
Asignación de pilotos con push automático NUEVO
Al asignar un piloto, el sistema envía automáticamente una notificación push a su teléfono. El monitor ve "📱 Push HH:MM" confirmando el envío.
✓
Alertas automáticas por tiempo excedido
Visual y sidebar con los pedidos que superan el tiempo estimado. Contador rojo parpadeante para entregas en alerta.
✓
GPS en tiempo real por piloto
Enlace "📍 Ver · X min ago" en cada pedido en ruta, que abre Google Maps con la última ubicación del piloto registrada.
✓
Reportes y exportación Excel CORE
Vista de reportes con resumen por período (hoy / semana / mes / personalizado), desglose por piloto con tasa de entrega y tiempo promedio, exportable a .xlsx.
✓
Sidebar de pilotos activos
Panel lateral con estado de cada piloto: pedidos asignados, en ruta y alertas activas en tiempo real.
🏍️ Portal del Piloto (PWA)
✓
App instalable sin App Store NUEVO
PWA (Progressive Web App) instalable directamente desde Chrome. El piloto tiene un ícono de app en su teléfono sin pasar por Google Play ni App Store.
✓
Notificaciones push nativas NUEVO
Implementación propia con Web Push (VAPID) + Service Worker. Llega la notificación aunque la app esté cerrada. Sin depender de Firebase ni OneSignal.
✓
Vista de pedidos asignados del día
Tarjetas con toda la info del despacho: cliente, dirección destacada, descripción, botón para llamar y acciones de estado.
✓
Confirmación de salida y entrega con GPS
El piloto toca "Confirmar Salida" y "Confirmar Entregado". El sistema registra la hora exacta y las coordenadas GPS en ambos eventos.
✓
GPS continuo con wake lock
La app activa el GPS automáticamente, lo mantiene activo en background, envía coordenadas cada 30 segundos a Supabase, y activa wake lock para que la pantalla no se apague en ruta.
✓
Alerta sonora + vibración al recibir pedido
Cuando llega un pedido mientras la app está abierta, suena una alarma (Web Audio API, sin archivos externos) y el teléfono vibra en patrón de alerta.
✓
Actualización realtime con polling de respaldo
WebSocket de Supabase para actualizaciones inmediatas + polling cada 30 segundos como red de seguridad si el websocket se cae.
🔐 Seguridad e Infraestructura
✓
Row Level Security (RLS) en base de datos SEGURIDAD
Políticas de seguridad a nivel de PostgreSQL que impiden que un piloto acceda a datos de otro piloto, incluso si manipula las peticiones directamente a la API.
✓
Content Security Policy (CSP) en headers HTTP SEGURIDAD
Headers de seguridad configurados en Vercel: CSP, X-Frame-Options, HSTS, XSS Protection. Bloquea inyecciones de scripts externos no autorizados.
✓
Sanitización XSS en todos los formularios SEGURIDAD
Todos los campos de texto pasan por función de sanitización antes de renderizarse. Previene ataques de Cross-Site Scripting.
✓
Autenticación centralizada por roles
Un único sistema de login. El rol del usuario en la BD determina automáticamente a qué portal accede. Intento de acceso a portal incorrecto redirige al login.
✓
Edge Function serverless para push NUEVO
Backend serverless en Supabase que maneja el cifrado VAPID para Web Push. La clave privada nunca sale del servidor. Cero infraestructura que mantener.
📋 Documentación y Soporte
✓
Guía del piloto imprimible NUEVO
Página web con instructivo paso a paso para pilotos. Descargable como PDF. Cubre instalación PWA, activación de notificaciones, flujo de pedidos y solución de problemas.
✓
Documentación del sistema para el cliente
Documentación completa en /docs: módulos, roles, flujos, reglas de negocio, tecnología y accesos. Descargable como PDF.

Historia del desarrollo
Fase 1
Sistema base
Login, roles, módulos Monitor y Call Center. Creación de pedidos, estados, tabla en tiempo real con Supabase Realtime.
Fase 2
Portal del Piloto + GPS
App mobile-first para pilotos. Autenticación, vista de pedidos, confirmar salida/entrega, GPS con watchPosition y guardado en BD cada 30 segundos.
Fase 3
PWA + Reportes
Instalación como PWA sin App Store, manifest.json, ícono Farmapaz, wake lock, alerta sonora. Módulo de reportes con exportación Excel.
Fase 4
Seguridad + RLS
Row Level Security en PostgreSQL, CSP en headers HTTP, sanitización XSS, función get_user_rol VOLATILE, políticas de inserción/lectura por rol.
Fase 5 · Mayo 2026
Notificaciones Push Nativas (v2.0)
Migración de Firebase → OneSignal → Web Push nativo. Service Worker propio (sw.js sin CDN). VAPID key pair. Edge Function serverless send-push. Indicador de push en monitor. Guía del piloto. Documentación completa.
