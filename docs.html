Módulos del sistema
Tres portales, un sistema integrado

Cada usuario accede a su módulo con credenciales propias. La información fluye en tiempo real entre los tres portales sin necesidad de actualizaciones manuales.

🖥️
Monitor
Panel central de operaciones. Crea pedidos, asigna pilotos, monitorea entregas en tiempo real, ve el GPS de cada piloto y accede a reportes.
🔗 /monitor
📞
Call Center
Vista simplificada para el equipo de atención. Consulta el estado de pedidos del día y actualiza información del cliente sin acceso a funciones de operación.
🔗 /callcenter
🏍️
Portal Piloto
App instalable en el teléfono del piloto. Recibe notificaciones push, ve sus pedidos asignados, activa GPS y confirma salida y entrega.
🔗 /piloto

Flujo de notificación push
1. Monitor asigna piloto al pedido
2. Sistema llama a la función send-push
3. Función recupera la suscripción del piloto
4. Push enviado vía Web Push / VAPID
5. Teléfono muestra la notificación aunque la app esté cerrada
6. Monitor ve "📱 Push 09:58" debajo del nombre del piloto
📍
Flujo de GPS
1. Piloto toca el indicador GPS en la app
2. App solicita permiso de ubicación al sistema
3. Coordenadas se guardan en Supabase cada 30 segundos
4. Monitor ve enlace "📍 Ver · X min ago" en la tabla
5. Al tocar el enlace abre Google Maps con la ubicación del piloto
Reglas del sistema
Lógica de negocio implementada

El sistema aplica automáticamente estas reglas sin requerir acción manual.

📅
Pedidos del día
Cada portal muestra únicamente los pedidos creados el día en curso. Los reportes permiten acceder al histórico completo filtrado por período.
🔒
Aislamiento de datos por rol
Un piloto solo puede ver sus propios pedidos. El call center solo puede leer, no modificar. El monitor tiene acceso completo. Esta seguridad está implementada a nivel de base de datos (RLS), no solo en la interfaz.
⏱️
Alertas de tiempo
El monitor muestra alertas visuales cuando un pedido en ruta supera el tiempo estimado. El contador de tiempo inicia en el momento exacto que el piloto confirma la salida.
🔔
Notificación push al asignar
Cada vez que el monitor asigna un piloto a un pedido, se envía automáticamente una notificación push al teléfono del piloto con el número de pedido, cliente y dirección. El sistema registra la hora exacta del envío.
🔄
Actualización en tiempo real
Todos los portales se actualizan automáticamente vía WebSocket (Supabase Realtime). No es necesario refrescar la página. Como respaldo adicional, el monitor se sincroniza también cada 15 segundos.
📍
GPS solo en estado activo
La ubicación del piloto solo es visible en el monitor cuando el pedido está en estado "en ruta" o "entregado" y el piloto tiene GPS activo. El enlace de mapa aparece junto al pedido correspondiente.
📊
Reportes automáticos
El módulo de reportes calcula automáticamente: total de pedidos, tasa de entrega, tiempo promedio por piloto y exporta todo a Excel con un click.
Tecnología
Infraestructura del sistema

Construido sobre plataformas de clase mundial, con cero infraestructura propia que mantener.

🟢
Supabase
Base de datos PostgreSQL, autenticación de usuarios, WebSockets en tiempo real y funciones serverless (Edge Functions) para el envío de push notifications.
▲
Vercel
Hosting global con CDN. Todos los archivos del sistema se sirven con alta disponibilidad desde múltiples regiones. SSL/HTTPS automático.
🔔
Web Push (VAPID)
Notificaciones push nativas del navegador sin depender de servicios de terceros. Funciona en Android Chrome instalado como PWA.
📱
Progressive Web App
La app del piloto se instala en el teléfono directamente desde Chrome, sin App Store ni Google Play. Funciona como una app nativa.
